# 06-独立按键控制LED亮灭

> 独立按键检测 + 软件消抖 + LED状态翻转

## 功能说明

- **K1（P3.1）**：每按一次，LED（D1）状态翻转一次（亮→灭→亮→灭…）
- 上电后LED默认熄灭，按下K1点亮，再按下熄灭，如此循环

## 硬件连接

| 外设 | 引脚 | 说明 |
|:---|:---|:---|
| LED（D1） | P2.0 | 低电平点亮（灌电流驱动） |
| 独立按键K1 | P3.1 | 按下为低电平，需软件消抖 |

## 运行效果

1. 上电后LED熄灭
2. **第1次按K1**：LED点亮
3. **第2次按K1**：LED熄灭
4. **第3次按K1**：LED点亮
5. 以此类推——每次按下翻转一次

## 代码解析

### 按键消抖标准流程

```c
if (KEY_1 == 0)                     // ① 检测按下
{
    Delay_ms(KEY_DEBOUNCE_MS);      // ② 等抖动过去
    if (KEY_1 == 0)                 // ③ 再次确认
    {
        while (KEY_1 == 0);         // ④ 等待松开（防连击）
        Delay_ms(KEY_DEBOUNCE_MS);  // ⑤ 松手同样有抖动，再消抖一次
        return KEY_VALUE_K1;        // 返回键值，main 只负责处理流程
    }
}
```

### LED翻转核心语句

```c
/* main.c：只判断键值，不碰引脚 */
if (KEY_Scan() == KEY_VALUE_K1)
{
    LED_Toggle();
}

/* LED.c：真正操作引脚 */
sbit LED_D1 = P2^0;
LED_D1 = !LED_D1;   // 取反：0→亮，1→灭
```

### 关键技术点

| 知识点 | 代码 | 说明 |
|:---|:---|:---|
| 消抖 | `Delay_ms(KEY_DEBOUNCE_MS)` | 机械按键抖动约5-20ms，延时跳过抖动期 |
| 防连击 | `while (KEY_1 == 0);` | 按着不松手只会触发一次 |
| 位操作 | `sbit LED_D1 = P2^0;` | 单独控制P2.0这一个引脚（放在 LED.c 内） |
| 状态翻转 | `LED_Toggle();` | 取反运算封装进驱动，main 不碰引脚 |
