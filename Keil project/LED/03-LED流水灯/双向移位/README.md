# 03-流水灯

> 3种方法实现流水灯效果，从底层位运算到库函数

## 实验目标

掌握循环移位原理，对比手写移位与 `_crol_`/`_cror_` 库函数的区别，最终实现双向来回流水灯。

## 知识点

| 知识点 | 说明 |
|:---|:---|
| `(x << 1) \| (x >> 7)` | 手写循环左移（底层原理） |
| `_crol_(x, 1)` | 库函数循环左移（需 `#include <intrins.h>`） |
| `_cror_(x, 1)` | 库函数循环右移 |
| `typedef unsigned char u8` | 类型重定义，简化代码 |
| `#define LED_PORT P2` | 宏定义端口别名 |

|:---|:---|:---|:---|
| `双向移位/`（本目录） | [main.c](main.c) | `_crol_` + `_cror_` | **双向来回流水灯**（当前活动文件） |

| `库函数移位/` | [main-keil头文件.c](../库函数移位/main-keil头文件.c) | `_crol_` 库函数 | 一行 `_crol_(x,1)` 搞定，简洁高效 |

| 文件 | 说明 |

## 推荐学习顺序

```
手写移位 → 理解位运算原理
    ↓
库函数   → 一行替代，感受效率
    ↓
双向来回 → 组合运用，最佳实践
```

## 如何切换实现

Keil 工程中只能有一个 `main()` 函数。这里把三种实现拆成了三个**独立工程目录**，每个都有自己的 `project.uvproj`——**想编译哪个，直接用 Keil 打开对应目录的工程即可**，不需要来回改文件名。

## 核心代码对比

```c
// 方法1：手写（理解原理）
x = (x << 1) | (x >> 7);

// 方法2：库函数（简洁）
x = _crol_(x, 1);

// 两者完全等价！
```
