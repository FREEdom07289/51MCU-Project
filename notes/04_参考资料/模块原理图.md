# 普中A2开发板模块原理图

> 整理各模块的引脚连接和电路原理，方便开发时快速查阅。

---

## 1. LED 模块

### 1.1 引脚连接

| LED | 正极（阳极） | 负极（阴极） | 控制引脚 |
|:---:|:---:|:---:|:---:|
| D1 | VCC（经R1限流） | P2.0 | P2.0 |
| D2 | VCC（经R2限流） | P2.1 | P2.1 |
| D3 | VCC（经R3限流） | P2.2 | P2.2 |
| D4 | VCC（经R4限流） | P2.3 | P2.3 |
| D5 | VCC（经R5限流） | P2.4 | P2.4 |
| D6 | VCC（经R6限流） | P2.5 | P2.5 |
| D7 | VCC（经R7限流） | P2.6 | P2.6 |
| D8 | VCC（经R8限流） | P2.7 | P2.7 |

### 1.2 电路原理

```
VCC（+5V）
   │
   ├─[R1 限流电阻]─[LED1 正极]─[LED1 负极]─── P2.0
   ├─[R2 限流电阻]─[LED2 正极]─[LED2 负极]─── P2.1
   ├─[R3 限流电阻]─[LED3 正极]─[LED3 负极]─── P2.2
   ├─[R4 限流电阻]─[LED4 正极]─[LED4 负极]─── P2.3
   ├─[R5 限流电阻]─[LED5 正极]─[LED5 负极]─── P2.4
   ├─[R6 限流电阻]─[LED6 正极]─[LED6 负极]─── P2.5
   ├─[R7 限流电阻]─[LED7 正极]─[LED7 负极]─── P2.6
   └─[R8 限流电阻]─[LED8 正极]─[LED8 负极]─── P2.7
```

### 1.3 点亮方式

- **低电平点亮**：P2.x 输出 `0`（0V），电流从 VCC → 电阻 → LED → P2.x（灌电流）
- **高电平熄灭**：P2.x 输出 `1`（5V），两端无电压差，LED不亮
- **原因**：51单片机灌电流能力强（~20mA），拉电流能力弱（<1mA），LED需要3-5mA

## 2. 独立按键模块

已核对攻略第13章（官方源码 `sbit KEY1=P3^1; KEY2=P3^0; KEY3=P3^2; KEY4=P3^3;`）：

| 按键 | 引脚 | 按下电平 |
|:---:|:---:|:---:|
| K1 | P3.1 | 低电平（0） |
| K2 | P3.0 | 低电平（0） |
| K3 | P3.2 | 低电平（0） |
| K4 | P3.3 | 低电平（0） |

- 按键为机械开关，按下导通（低电平0），松开断开（高电平1）
- 存在机械抖动（5-20ms），需要软件消抖
- 4 个独立按键各占一个引脚，互不共用；矩阵按键（4×4，S1-S16）接 P1 口

## 3. 数码管模块

普中A2 数码管模块为 **2 个四位一体共阴数码管**（共 8 位），采用动态扫描方式驱动（已核对攻略第11/12章）：

- **段选（a-g、dp）**：P0 口 → 74HC245 缓冲 → 数码管段引脚（共阴，段码 0x3F…0x71）
- **位选**：P2.2 / P2.3 / P2.4 三根引脚 → 74HC138 译码器 → 8 个位选端（Y0~Y7）
  - 官方源码：`sbit LSA=P2^2; LSB=P2^3; LSC=P2^4;`（LSA/LSB/LSC 为 74HC138 地址输入 A/B/C）
  - 无锁存器——位选由 74HC138 直接译码，每 1ms 左右切换一位，利用视觉暂留（约 24ms）实现 8 位同时显示
- **引脚复用说明**：P2.2/P2.3/P2.4 同时连到 LED（D3/D4/D5）与 74HC138 位选输入，练习时拔掉无关跳线帽即可

---

## 4. 蜂鸣器模块

普中A2 蜂鸣器为**无源压电式蜂鸣器**，由 P2.5 控制（已核对攻略第10章）：

- **控制引脚**：P2.5（官方源码 `sbit BEEP=P2^5;`）
- **驱动方式**：P2.5 → ULN2003D 达林顿驱动（非直接驱动），`BEEP=0` 导通发声、`BEEP=1` 关闭
- **无源蜂鸣器**：需要外部提供频率（用延时翻转电平产生方波）才能发声，不同延时频率 → 不同音调
- 与 LED D6 共用 P2.5，练习蜂鸣器时注意拔掉 LED 相关跳线

---

## 5. 引脚冲突注意事项

普中A2开发板上**多个模块共用同一组P口引脚**，使用时需注意：

- **P2口**：
  - P2.0-P2.7 同时连接 8 个 LED（低电平点亮）
  - P2.2/P2.3/P2.4 同时连接数码管位选（→ 74HC138 译码）
  - P2.5 同时连接蜂鸣器（→ ULN2003D 驱动）
- **练习建议**：单独练习某个模块时，拔掉其他模块的跳线帽，避免互相干扰（如 LED 实验拔数码管位选跳线、蜂鸣器实验拔 LED 相关跳线）
