# 普中开发板模块原理图（A2 + 2/3/4）

> **板型**：本板按使用者确认与丝印记为**普中 A2**；但攻略与原理图通篇只写"普中-2/3/4"，未出现板名"A2"，**"普中-2 就是 A2"目前没有文档依据，列为待确认**（见 §7.2）。
> §1–§5 为 A2 侧已核对内容；§6 为普中-2/3/4 图纸速查，**在命名关系确认前不并入 A2 结论**，仅作对照。

## 1. LED 模块

### 1.1 引脚连接

| LED | 正极（阳极） | 负极（阴极） | 控制引脚 |
|:---:|:---:|:---:|:---:|
| D1 | VCC（经R1限流） | P2.0 | P2.0 |
| D2 | VCC（经R2限流） | P2.1 | P2.1 |
| D3 | VCC（经R3限流） | P2.2 | P2.2 |
| D4 | VCC（经R4限流） | P2.3 | P2.3 |
| D5 | VCC（经R5限流） | P2.4 | P2.4 |
| D6 | VCC（经R6限流） | P2.5 | P2.5 |
| D7 | VCC（经R7限流） | P2.6 | P2.6 |
| D8 | VCC（经R8限流） | P2.7 | P2.7 |

### 1.2 电路原理

```
VCC（+5V）
   │
   ├─[R1 限流电阻]─[LED1 正极]─[LED1 负极]─── P2.0
   ├─[R2 限流电阻]─[LED2 正极]─[LED2 负极]─── P2.1
   ├─[R3 限流电阻]─[LED3 正极]─[LED3 负极]─── P2.2
   ├─[R4 限流电阻]─[LED4 正极]─[LED4 负极]─── P2.3
   ├─[R5 限流电阻]─[LED5 正极]─[LED5 负极]─── P2.4
   ├─[R6 限流电阻]─[LED6 正极]─[LED6 负极]─── P2.5
   ├─[R7 限流电阻]─[LED7 正极]─[LED7 负极]─── P2.6
   └─[R8 限流电阻]─[LED8 正极]─[LED8 负极]─── P2.7
```

### 1.3 点亮方式

- **低电平点亮**：P2.x 输出 `0`（0V），电流从 VCC → 电阻 → LED → P2.x（灌电流）
- **高电平熄灭**：P2.x 输出 `1`（5V），两端无电压差，LED不亮
- **原因**：51单片机灌电流能力强（~20mA），拉电流能力弱（<1mA），LED需要3-5mA

## 2. 独立按键模块

已核对攻略第13章（官方源码 `sbit KEY1=P3^1; KEY2=P3^0; KEY3=P3^2; KEY4=P3^3;`）：

| 按键 | 引脚 | 按下电平 |
|:---:|:---:|:---:|
| K1 | P3.1 | 低电平（0） |
| K2 | P3.0 | 低电平（0） |
| K3 | P3.2 | 低电平（0） |
| K4 | P3.3 | 低电平（0） |

- 按键为机械开关，按下导通（低电平0），松开断开（高电平1）
- 存在机械抖动（5-20ms），需要软件消抖
- 4 个独立按键各占一个引脚，互不共用；矩阵按键（4×4，S1-S16）接 P1 口

## 3. 数码管模块

普中A2 数码管模块为 **2 个四位一体共阴数码管**（共 8 位），采用动态扫描方式驱动（已核对攻略第11/12章）：

- **段选（a-g、dp）**：P0 口 → 74HC245 缓冲 → 数码管段引脚（共阴，段码 0x3F…0x71）
- **位选**：P2.2 / P2.3 / P2.4 三根引脚 → 74HC138 译码器 → 8 个位选端（Y0~Y7）
  - 官方源码：`sbit LSA=P2^2; LSB=P2^3; LSC=P2^4;`（LSA/LSB/LSC 为 74HC138 地址输入 A/B/C）
  - 无锁存器——位选由 74HC138 直接译码，每 1ms 左右切换一位，利用视觉暂留（约 24ms）实现 8 位同时显示
- **引脚复用说明**：P2.2/P2.3/P2.4 同时连到 LED（D3/D4/D5）与 74HC138 位选输入，练习时拔掉无关跳线帽即可

## 4. 蜂鸣器模块

普中A2 蜂鸣器为**无源压电式蜂鸣器**，由 P2.5 控制（已核对攻略第10章）：

- **本板定案**：板型已确认为普中 A2，驱动器件即 ULN2003D，`P2.5=1` 导通发声；上传版所称"三极管 Q5"不作为本板依据
- **控制引脚**：P2.5（官方源码 `sbit BEEP=P2^5;`）
- **驱动方式**：P2.5 → ULN2003D 达林顿驱动（非直接驱动）；ULN2003D 反相，故 `BEEP=1` 导通发声、`BEEP=0` 关闭
- **无源蜂鸣器**：需要外部提供频率（用延时翻转电平产生方波）才能发声，不同延时频率 → 不同音调
- 与 LED D6 共用 P2.5，练习蜂鸣器时注意拔掉 LED 相关跳线

---

## 5. 引脚冲突注意事项

普中A2开发板上**多个模块共用同一组P口引脚**，使用时需注意：

- **P2口**：
  - P2.0-P2.7 同时连接 8 个 LED（低电平点亮）
  - P2.2/P2.3/P2.4 同时连接数码管位选（→ 74HC138 译码）
  - P2.5 同时连接蜂鸣器（→ ULN2003D 驱动）
  - P2.5 / P2.6 / P2.7 同时是 LCD1602 的 RW / RS / E 控制口，**蜂鸣器与 LCD1602 不能同时使用**
- **练习建议**：单独练习某个模块时，拔掉其他模块的跳线帽，避免互相干扰（如 LED 实验拔数码管位选跳线、蜂鸣器实验拔 LED 相关跳线）

## 6. 普中 2/3/4 图纸速查（型号关系待确认，暂作对照）

> **适用范围**：本节对应文档中的"普中-2/3/4"。本板叫"普中 A2"，两者是否同一型号**尚未证实**（见 §7.2），因此本节暂按对照资料处理，不直接当作 A2 的接线依据。
> **依据**：《普中51单片机开发攻略 V1.3（基于普中-2/3/4）》配套原理图（2023-08-28 单页 PDF）。
> **收录范围**：只收 A2 部分未覆盖的模块。LED、独立按键、数码管、蜂鸣器的权威结论见 §7，不在此重复。
> **核验状态**：标注"待核对"的，是单页 PDF 文字层无法可靠确认、需对照原图或实物才能定论的项，不要当成既成事实。

### 6.1 单片机最小系统

- 40 脚 8051 兼容 MCU（CPU1），P0 / P1 / P2 / P3 四组 IO 全部引出。
- 晶振：11.0592MHz（Y2）+ 两个 33pF 负载电容。
- 复位：10k 上拉 + 10uF 电容，高电平复位。
- EA（31 脚）上拉，使用片内程序存储器；VCC = 5V。

### 6.2 电源模块

- 外部输入网络：`D5V` / `DIN5V`；U9（AMS1117-3.3）输出 `D3.3V`。
- 5V 供 51、LED、数码管、继电器等；3.3V 供 NRF24L01 等无线模块。
- 每个电源脚就近 104 去耦；3.3V 器件不要直接接 5V IO。

### 6.3 74HC595（U6）

- 8 位串入并出移位寄存器：`SER` 数据、`SRCLK` 移位时钟、`RCLK` 锁存时钟、`OE` 输出使能、`SRCLR` 清空。
- `QA–QH` 并行输出，`QH'` 用于级联。
- 与 MCU 连接：`SER=P3.4`、`RCLK=P3.5`、`SRCLK=P3.6`（攻略 15.2 正文写"P3.4-P3.6"，15.3 源码 `sbit` 逐条确认；官方引脚修订版一致）。
- 编程关联：先移入 8 位，再给 `RCLK` 一个上升沿锁存输出。

### 6.4 LCD12864 / TFT 接口

- 并行数据：`LCD_D0–LCD_D15`；控制：`LCD_WR`、`LCD_EN`、`LCD_RS`。
- 触摸：`T_PEN`、`T_CS`；SD 卡：`SPI_MISO` / `SPI_SCK` / `SPI_MOSI` + `SD-CS`。
- 与 LCD1602 共用部分控制网络，使用前核对跳线。

### 6.5 ADC：ET2046（U8）

- 12 位、8 通道：`AIN0–AIN3`、`X±`、`Y±`、`NTC1`、`GR1`。
- 串行控制：`DIN=P3.4`、`CS=P3.5`、`DCLK=P3.6`、`BUSY=P3.7`；**`DOUT` 未确认**（修订版明确标为"P?"，不猜）。
- 触摸：`PENIRQ` 中断输出；X± / Y± 接电阻触摸屏。
- 常见用途：电位器电压、光敏电阻、NTC 测温、触摸屏。
- 编程关联：先发控制字选通道，再读转换结果；参考电压取 VCC。

### 6.6 DAC：PWM + LM358

- `DAC1` 网络标注连接到 `AIN3`、P2.1。
- 单片机输出 PWM → RC 滤波 → LM358 缓冲，得到近似模拟电压。
- 编程关联：调占空比改变输出；滤波时间常数决定纹波与响应速度。

### 6.7 EEPROM：24C02（U3）

- I²C 接口：`SCL` / `SDA`；`E0–E2` 地址脚，`WE` 写保护。
- 与 MCU 连接：`SDA=P2.0`、`SCL=P2.1`（官方引脚修订版逐线读取；攻略正文未列出，标为"已按原理图核对、待实测"）。
- 编程关联：7 位地址 `0x50 | A2A1A0`；页写后需等待约 5ms。

### 6.8 实时时钟：DS1302（U1）

- 32.768kHz 晶振（X1 / X2）；三线接口 `CE`（复位）、`I/O`、`SCLK`；带备用电池 B1。
- 与 MCU 连接：`CE=P3.5`、`I/O=P3.4`、`SCLK=P3.6`（官方引脚修订版；攻略正文未列出）。
- **与 74HC595、ET2046 共用 P3.4–P3.6，三个模块不能同时使用。**
- 编程关联：数据为 BCD 码；写入前先关闭写保护。

### 6.9 温度传感器：DS18B20

- 单总线：VCC / GND / `I/O`，数据线需 4.7k 上拉。
- 编程关联：时序敏感，读写字期间建议关中断。

### 6.10 红外接收：HS0038（IR1）

- 三脚：Vdd / Vss / OUT，OUT 接 P3.2。
- **P3.2 同时是 K3 和外部中断 0 引脚——红外接收与 K3 不能同时使用**（见攻略外部中断章节）。
- 编程关联：38kHz 载波解调，输出低电平脉宽区分 0 / 1。

### 6.11 步进电机：ULN2003D（U14）

- 五线四相减速步进电机接口；`IN1–IN7` / `OUT1–OUT7` 达林顿阵列驱动。
- 与 MCU 连接：`IN1=P1.0`、`IN2=P1.1`、`IN3=P1.2`、`IN4=P1.3`、`IN5=P2.5`；IN6 / IN7 使用情况未确认（官方引脚修订版）。
- P1 同时被矩阵键盘和 NRF24L01 接口使用，**不能同时接**；该区域与蜂鸣器 `BEEP` 网络相邻。
- 编程关联：按四相八拍顺序表输出，电机与板子必须共地。

### 6.12 8×8 LED 点阵

- 行线 `A1–A8`，列线 `DPa–DPh`；RP20 为 10k 排阻。
- 编程关联：逐行扫描 + 视觉暂留，注意扫描频率避免闪烁。

### 6.13 NRF24L01 无线接口

- 模块接口 P2（8 pin）：`IRQ=P1.6`、`MISO=P1.4`、`MOSI=P1.1`、`SCK=P1.3`、`CSN=P1.2`（经 470Ω）、`CE=P1.7`（经 470Ω）；**3.3V 供电**。
- P1 同时被矩阵键盘、步进电机 IN1–IN4 使用，**不能同时接**；这是模块接口，不是裸芯片 QFN 脚号。
- 编程关联：配置寄存器、地址与频道，收发双方参数必须一致。

### 6.14 USB 转 TTL：CH340G（U11）

- USB `D+` / `D-` 经 27Ω 电阻到 CH340G；`TXD` / `RXD` 经跳线接 MCU 的 P3.0 / P3.1。
- 编程关联：程序下载与串口调试共用同一路串口，下载时不能同时被助手占用。

### 6.15 74HC245（U4）

- 8 路双向缓冲：`A0–A7` ↔ `B0–B7`，`DIR` 选方向，`OE` 使能。
- 本板用于 P0 口驱动数码管段选（P0 内部无上拉，需缓冲增强驱动）。
- 编程关联：纯硬件缓冲，无需软件配置。

### 6.16 网络名速查

| 网络名 | 含义 |
|:---|:---|
| `D5V` / `DIN5V` | 5V 电源输入 / 分配 |
| `D3.3V` | 3.3V 电源（无线模块等） |
| `GND` | 地 |
| `P00–P07` / `P10–P17` / `P20–P27` / `P30–P37` | 四组 IO |
| `LED1–LED8` | 数码管位选 / LED 相关网络 |
| `SMG_A`–`SMG_DP` | 数码管段选 |
| `BEEP` | 蜂鸣器驱动 |
| `KEY1–KEY4` | 独立按键 |
| `TXD` / `RXD` | 串口收发 |

### 6.17 建议学习顺序（2/3/4 版）

1. 最小系统 + 电源（先确认能下载、能复位）
2. LED（GPIO 输出）
3. 独立按键（GPIO 输入 + 消抖）
4. 数码管（段选 / 位选 / 译码）
5. 蜂鸣器（电平驱动 / 方波）
6. 中断与定时器（外部中断、定时中断）
7. 串口（通信参数、收发中断）
8. 显示、存储、传感器、无线（LCD、24C02、DS1302、DS18B20、ADC、NRF）

### 6.18 器件级核对要点（来自官方引脚修订版）

- **74HC595**：不同厂商对 `Q0–Q7` / `QA–QH`、`Q7S` / `QH'` 命名不同，按物理脚号和数据手册核对；`OE` 低有效，`SRCLR` 低有效。
- **74HC138**：三个使能必须同时满足 `E1=低、E2=低、E3=高`；选中输出为低，其余为高。
- **74HC245**：`DIR=高` 为 A→B，`OE` 低有效；原理图 `A0/B0` 与官方 `A1/B1` 编号差 1，读图要同时看物理脚号。
- **24C02**：`A0–A2` 决定器件地址，`WP` 为写保护；地址计算见 §6.7。
- **DS1302**：`CE` 是复位 / 使能，不是 SPI 片选；读写时序与 SPI 无关。
- **XPT2046 / ET2046**：`BUSY=P3.7`、`DIN/CS/DCLK=P3.4/P3.5/P3.6`，`DOUT` 未确认；不要把触摸接口当标准 SPI 使用。
- **ULN2003**：`IN1–IN7` 与 `OUT1–OUT7` 反向编号（IN1→OUT16 脚），`COM` 接续流二极管公共端。
- **CH340G**：串口必须 **TX 对 RX、RX 对 TX** 交叉；`V3` 按手册接去耦电容。
- **DS18B20**：TO-92 脚序按器件顶标和数据手册确认，**不要按三根线的左右位置猜**。
- **极性判断原则**：共阴 / 共阳、有源 / 无源、有效电平，必须有"PDF 正文、器件型号、实测"三者之一作依据，不能只凭网络名推断。

## 7. 官方攻略核对：四处引脚冲突

> **核对依据**：《普中51单片机开发攻略 V1.3——基于普中-2&普中-3&普中-4》（PDF）。攻略基于普中-2/3/4，其四处结论与仓库 A2 记录完全一致——这是**旁证**，不等于证明两者是同一块板（见 §7.2）。

| 项目 | 仓库 A2 记录 | 上传版说法 | 官方攻略依据 | 结论 |
|:---|:---|:---|:---|:---|
| 独立按键 | K1=P3.1、K2=P3.0、K3=P3.2、K4=P3.3，低电平按下 | "P32、P33、P34、P35" | **第13章 13.2 硬件设计**（PDF 第151页）："K1 连接在 P3.1 上，K2 连接在 P3.0 上，K3 连接在 P3.2 上，K4 连接在 P3.3 上……按下后对应 IO 即为低电平" | 仓库正确；上传版 **P3.2–P3.5 不成立** |
| 矩阵按键 | 接 P1 口 | "P20–P27 与 P10–P17" | **第14章 14.2 硬件设计**（PDF 第158页）："4*4 矩阵按键引出的 8 根控制线直接连接到 51 单片机的 P1 口上。P17 连接第 1 行，P13 连接第 1 列" | 仓库正确；上传版 **不成立** |
| 数码管 | 共阴，段选 P0，位选 P2.2–P2.4（74HC138） | "无法确认共阴 / 共阳" | **第12章 12.1 数码管介绍**（PDF 第137页）："开发板上使用的数码管是 2 个四位一体的共阴极数码管"；**12.3 硬件设计**（第144页）：段选经 74HC245，位选 LSA=P2^2、LSB=P2^3、LSC=P2^4 | 仓库正确；共阴已由攻略明确，上传版过度保守 |
| 蜂鸣器 | P2.5，ULN2003D，无源，`P2.5=1` 响 | "三极管 Q5（2TY）+ 470R，有效电平未确认" | **第10章 10.2 硬件设计**（PDF 第126页）：无源压电式，P2.5 经 ULN2003 驱动，`P2.5=1` 时 BEEP 输出低电平、蜂鸣器导通，`P2.5=0` 关闭 | 仓库正确；板型为 A2，**按 ULN2003 + `P2.5=1` 导通定案**，上传版"三极管 Q5"不作为本板依据（来源待确认，见 §7.2） |

**补充核对（非冲突，用于交叉验证）**

- LED：**第9章 9.3 硬件设计**（PDF 第113页）：D1–D8 接 P2.0–P2.7，采用**共阳接法**，低电平点亮——与 §1 一致。
- 红外与 K3 共用 P3.2：攻略外部中断章节已明确，写入 §6.10。

**关于蜂鸣器驱动的不一致说明**：攻略 10.2 正文先写到"通过三极管放大"，随后明确"并没有使用三极管，而是使用 ULN2003 达林顿管"，电路说明以 ULN2003 为准；上传版原理图笔记识别出"三极管 Q5 / 470R"，与攻略不符。**本板按 A2 定案：P2.5 + ULN2003 + `P2.5=1` 导通**；至于 Q5 是读图误差还是另一板型画法，取决于"A2 与普中-2 是否同型号"，目前**来源待确认**，不影响上面的定案。

> 《官方引脚修订版》给出了 595 / 24C02 / DS1302 / ADC / 步进 / NRF 的逐线连接，已并入 §6；攻略正文未列出的项标注为"按原理图核对、待实测"，不再笼统写"待核对"。

核查范围：攻略 V1.3 全文、配套《普中-2&普中-3&普中-4开发板原理图.pdf》、仓库内 51 笔记。

**结论**

- **已确认**：本板被称作（并丝印为）普中 A2；攻略与原理图是普中-2/3/4 的资料。
- **待确认**：A2 是否就是普中-2。现有依据只有"攻略基于 2/3/4"和"A2 记录与攻略结论一致"这类**旁证**，不能据此判定同一块板。

**若日后证实两者等同**，需要重新归位：

1. §6 中属于普中-2 的模块（595 / 24C02 / DS1302 / ET2046 / ULN / NRF）可直接适用于本板，§8.2 并入 §8.1；
2. 蜂鸣器"三极管 Q5 / 470R"与攻略 10.2（ULN2003）的矛盾要重新判断：同板则更可能是读图误差；
3. §7 四处冲突结论需按"普中-2 = A2"重走一遍核对；
4. 本段结论与文首板型说明同步改写。

**若证实两者不同**：维持现状，§6 仅作对照，A2 的接线以 §1–§5 和实物为准。
