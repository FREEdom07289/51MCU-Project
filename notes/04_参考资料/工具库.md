## 1. 头文件对比：`REGX52.H` vs `reg52.h`

你的项目同时使用了两者：

| 头文件        | 来源           | 适用芯片        | 你的使用位置                     |
| :--------- | :----------- | :---------- | :------------------------- |
| `reg52.h`  | Keil C51 自带  | 通用8052/8051 | 1-3流水灯（手写移位、Keil头文件）       |
| `REGX52.H` | STC-ISP 工具提供 | STC89C52专用  | 01-点亮LED、02-LED闪烁、03-流水灯主版 |

### 对LED实验的影响

两者在 LED 实验层面**完全等价**，都定义了 `P2`、`P2^0` 等寄存器。区别在于 `REGX52.H` 额外定义了 STC 特有外设寄存器（EEPROM、看门狗、PCA等），后续高级实验时会用到。

### 头文件的核心作用

把单片机内部寄存器的**物理地址**映射为C语言变量名：

```c
// reg52.h / REGX52.H 内部大致做了这些事：
sfr P0 = 0x80;   // P0端口 → 地址0x80
sfr P1 = 0x90;   // P1端口 → 地址0x90
sfr P2 = 0xA0;   // P2端口 → 地址0xA0（LED控制用这个！）
sfr P3 = 0xB0;   // P3端口 → 地址0xB0

// 以及可位寻址的位：
sbit P2_0 = P2^0;
sbit P2_1 = P2^1;
// ... 以此类推
```

> 没有这些头文件，你的代码里就不能写 `P2 = 0xFE;`，而是要写 `*(unsigned char *)0xA0 = 0xFE;`。

## 2. `intrins.h` — 内联汇编函数库

### 2.1 常用函数

| 函数 | 对应汇编 | 作用 | 示例 |
|:---|:---:|:---|:---|
| `_crol_(c, b)` | `RL A` | 将 c **循环左移** b 位 | `_crol_(0xFE, 1)` → `0xFD` |
| `_cror_(c, b)` | `RR A` | 将 c **循环右移** b 位 | `_cror_(0x7F, 1)` → `0xBF` |
| `_nop_()` | `NOP` | 空操作，延时1个机器周期 | 精确时序控制 |
| `_irol_(i, b)` | — | 16位循环左移 | — |
| `_iror_(i, b)` | — | 16位循环右移 | — |

### 2.2 你的项目中的实际使用

```c
// 在 1-3LED流水灯/main.c 中：
#include <INTRINS.H>

// 从左往右扫：每次循环左移1位
LED_PORT = _crol_(LED_PORT, 1);   // D1→D2→...→D8

// 从右往左扫：每次循环右移1位
LED_PORT = _cror_(LED_PORT, 1);   // D8→D7→...→D1
```

### 2.3 `_crol_` 等价手写

```c
// 这两行完全等价：
x = _crol_(x, 1);
x = (x << 1) | (x >> 7);    // 你的 手写移位.c 用的就是这个
```

> **建议**：先手写理解原理，再用 `_crol_` 简化代码。你的项目里两个版本都保留了，这是很好的学习习惯。

## 3. `typedef` — 类型重定义（你的编码习惯）

你的流水灯主版代码中使用了类型重定义：

```c
typedef unsigned int u16;    // 16位无符号整数
typedef unsigned char u8;    // 8位无符号整数
```

### 为什么这样写？

| 好处 | 说明 |
|:---|:---|
| **简洁** | `u8` 比 `unsigned char` 少打很多字 |
| **语义清晰** | `u16` 一看就知道是16位，"u"=unsigned |
| **便于移植** | 换个平台只需改 typedef，不用全文替换 |

### 使用示例

```c
void delay_10us(u16 ten_us)   // 参数类型一目了然：16位无符号
{
    while(ten_us--);
}

void main()
{
    u8 i = 0;                 // 循环变量：8位够用（0~255）
    // ...
}
```

## 4. `#define` — 宏定义端口（你的编码习惯）

```c
#define LED_PORT P2   // 给 P2 起个别名
```

### 好处

换开发板时只需改一处：

```c
// 普中A2：LED接P2
#define LED_PORT P2

// 如果换成另一个板子，LED接P1：
#define LED_PORT P1    // ← 只改这一行，下面所有代码自动生效
```

## 5. 延时函数合集（来自你的项目）

你的5个源文件中出现了三种延时函数：

### 5.1 标准双循环延时（毫秒级）

```c
// 来源：02-LED闪烁/main.c
void Delay(unsigned int t)
{
    unsigned int i, j;
    for(i = t; i > 0; i--)
        for(j = 110; j > 0; j--);  // 内层110 ≈ 1ms（11.0592MHz经验值）
}
// 用法：Delay(500); → 约500ms
```

### 5.2 双循环变体

```c
// 来源：main-手写移位.c / main-keil头文件.c
void delay(unsigned int time)
{
    unsigned int i, j;
    for (i = 0; i < time; i++)
        for (j = 0; j < 120; j++);  // 内层120，稍微不同的经验值
}
// 用法：delay(500);
```

### 5.3 精简单循环延时

```c
// 来源：1-3LED流水灯/main.c
void delay_10us(u16 ten_us)
{
    while(ten_us--);   // 极简写法，适合粗略延时
}
// 用法：delay_10us(50000); → 约500ms
```

> 💡 以上都是**软件延时**（让CPU空转），实际时间取决于晶振频率。精确计时需要用定时器（后续课程会学）。

## 8. 开发软件工具链

### 8.1 Keil µVision

- **用途**：8051 / 兼容单片机 C 程序编写、编译、调试。
- **常见流程**：新建工程 → 选择芯片 → 添加源文件 → 编译 → 生成 HEX。
- **常见问题**：未勾选生成 HEX、头文件路径错误、重复定义、晶振 / 延时参数与实际不符（详见 [[代码规范#7. Keil 落地与编辑器配置]]）。

### 8.2 STC-ISP

- **用途**：STC 系列程序下载与部分选项配置。
- **流程**：选芯片型号 → 选串口 → 载入 HEX → 按提示重新上电 / 复位 → 下载。
- **注意**：不同芯片与软件版本界面不同；不要随意改动不理解的时钟、复位、引脚配置项。

### 8.3 Proteus

- **用途**：原理图仿真、单片机外围电路与程序联合仿真（取决于器件模型）。
- **适合练习**：LED、按键、数码管、LCD、定时器逻辑、简单传感器接口。
- **局限**：模型不等于真实器件，不能替代电源完整性、布线和干扰测试。

### 8.4 Multisim

- **用途**：模拟 / 数字电路分析与仿真。
- **适合练习**：分压、RC、二极管、三极管、运放、滤波、基础逻辑。
- **局限**：不适合把整块单片机开发板当真实硬件复现，模型精度有限。

### 8.5 嘉立创 EDA

- **用途**：原理图、PCB、封装管理、工程检查与制造文件输出。
- **流程**：原理图 + 网络检查 → 绑定封装 → 布局 → 布线 → DRC → Gerber。
- **注意**：软件检查通过不等于设计正确，仍需人工核对封装与电源路径。

### 8.6 串口调试助手

- **用途**：收发 UART 数据，观察单片机输出。
- **必设参数**：COM 口、波特率、数据位、停止位、校验位、文本 / HEX 模式——**收发双方必须完全一致**。

### 8.7 其他常用工具

| 工具 | 用途 | 适用场景 |
|:---|:---|:---|
| VS Code | 代码编辑、文本搜索、Markdown | C、脚本、文档 |
| Git | 版本管理 | 保存程序与原理图修改历史 |
| Obsidian | Markdown 知识库 | 本库笔记与双链 |
| Typora | Markdown 编辑与预览 | 编写 / 导出笔记 |
| PDF 阅读器 | 查看原理图、数据手册 | 放大、搜索、批注 |
| 逻辑分析软件 | 数字信号协议解码 | UART、I²C、SPI 排查 |

## 9. 电子测量与焊接工具

### 9.1 数字万用表

- **能测**：直流 / 交流电压、电阻、通断、二极管压降；部分型号可测电流、电容、频率。
- **单片机学习中的用途**：查 5V / 3.3V 电源、GND 连通、限流电阻、按键通断、短路与断路。
- **安全习惯**：测电压时表笔插电压孔；测电流必须串联，禁止电流档并接电源；测电阻前先断电并确认电容放电。

### 9.2 示波器

- **用途**：观察电压随时间变化。
- **适合观察**：时钟、PWM、串口波形、按键抖动、复位脉冲、传感器输出。
- **关键参数**：带宽、采样率、存储深度、探头倍率。
- **安全**：普通台式探头地夹通常与保护地相连，测前确认接地关系，避免地夹接到非地节点造成短路。

### 9.3 逻辑分析仪

- **用途**：捕获数字信号并按协议解码。
- **适合观察**：UART、I²C、SPI、单总线时序。
- **注意**：输入电压范围有限，接前确认 IO 电平兼容。

### 9.4 可调直流电源

- **使用习惯**：断电接线 → 先设电压和保守限流 → 检查后输出 → 观察电流是否异常。
- **注意**：限流不能替代接线检查。

### 9.5 焊接工具

| 工具 | 用途 | 注意 |
|:---|:---|:---|
| 恒温电烙铁 | 焊接通孔 / 贴片 | 温度按焊料、焊盘、器件要求设置 |
| 烙铁头 | 传热与成型 | 保持清洁并及时上锡 |
| 焊锡丝 | 形成焊点 | 选适合电子焊接的规格 |
| 助焊剂 | 改善润湿 | 用后按材料要求清洁 |
| 吸锡器 / 吸锡带 | 拆焊与清理 | 避免长时间加热焊盘 |
| 镊子 | 夹持小器件 | 防止短路和器件弹飞 |
| 放大镜 / 显微镜 | 检查焊点 | 查桥连、虚焊、极性 |
| 防静电用品 | 降低静电损伤 | 按实验环境规范接地 |

## 10. 常用接口与通信协议速查

| 接口 / 协议 | 常见信号 | 本板相关器件 / 区域 | 核心学习点 |
|:---|:---|:---|:---|
| GPIO | 输入 / 输出 | LED、独立按键 | 电平、方向、上拉 / 下拉 |
| UART | TX、RX | CH340G 下载 / 串口 | 波特率、帧格式 |
| I²C | SDA、SCL | 24C02 | 起始 / 停止、地址、ACK |
| SPI | SCK、MOSI、MISO、CS | NRF24L01 等接口 | 时钟极性 / 相位、片选 |
| 单总线 | DQ / I/O | DS18B20 | 复位、时隙、时序 |
| 移位接口 | SER、SRCLK、RCLK | 74HC595 | 移位与锁存 |
| ADC 串行接口 | DIN、DOUT、DCLK、CS | ET2046 | 采样命令、数据读取 |
| 并行显示总线 | DB 或 LCD_Dx | LCD1602 / TFT 接口 | 数据 / 控制时序 |
| PWM | 脉冲、占空比 | DAC(PWM) 区域 | 频率、占空比、滤波 |

### 10.1 读原理图的通用检查法

1. 先看模块标题和器件型号。
2. 找电源脚、地脚和电源网络名。
3. 找信号脚，沿网络标号追到单片机端口。
4. 检查上拉、下拉、限流、驱动、电平转换器件。
5. 查看接口连接器的针脚顺序。
6. 对照数据手册确认引脚功能与电气限制。
7. 实物断电先通断检查，上电后再测电压和波形。

## 11. 工程流程

### 11.1 51 单片机模块开发流程

1. 从原理图确认模块接线与 IO。
2. 查模块核心器件数据手册。
3. 编写最小测试程序。
4. 在 Proteus（若模型可用）中做逻辑验证。
5. Keil 编译并生成 HEX。
6. 用 STC-ISP 下载到开发板。
7. 用万用表 / 示波器 / 逻辑分析仪检查实际信号。
8. 记录测试结果、已知问题和修订内容。

### 11.2 模电电路学习流程

1. 画出待分析电路并标注节点。
2. 明确电源、输入、输出和地。
3. 手算：等效电阻、偏置、增益、时间常数。
4. 用 Multisim 验证直流工作点与瞬态响应。
5. 用实际仪器测量。
6. 比较理论、仿真、实测差异，分析模型、容差与测量误差。

### 11.3 PCB 设计流程

1. 明确功能和电气指标。
2. 绘制原理图。
3. 完成 ERC 与人工网络核对。
4. 选择正确封装和器件尺寸。
5. 布局，优先安排连接器、电源和关键器件。
6. 布线，检查电流路径、回流路径和间距。
7. DRC 与人工复核。
8. 输出制造文件。
9. 焊接后先查短路，再限流上电，分模块测试。

## 12. 学习资料与官方文档入口

优先查官方资料，不要只依赖转载：

- **STC**：对应具体型号的数据手册、用户手册、下载工具说明。
- **Nexperia / TI**：74HC595、74HC138、74HC245 等逻辑器件数据手册。
- **TI**：LM358、ULN2003 系列数据手册。
- **Analog Devices / Maxim**：DS1302 相关资料。
- **Microchip**：24C02 及兼容 EEPROM 数据手册。
- **Analog Devices**：DS18B20 相关资料（原厂归属与版本需核对）。
- **WCH**：CH340G 官方资料与驱动。
- **Keil**：µVision 用户文档。
- **Proteus / NI**：仿真软件官方帮助与器件模型说明。
- **嘉立创 EDA**：官方教程与设计规则说明。
- **普中**：[[模块原理图]] 所依据的《普中51单片机开发攻略 V1.3（基于普中-2/3/4）》及配套原理图。

> 搜索时把完整型号、后缀和封装一起搜，同系列不同后缀可能存在电气参数差异。
