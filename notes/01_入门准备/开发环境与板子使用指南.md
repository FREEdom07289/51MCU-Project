## 一、核心结论



1. 你的开发板是**普中 A2**，主控 **STC89C52RC**（8051 内核，Flash 8KB，RAM 512B），晶振 **11.0592MHz**。 \[教材 攻略 p.24-26]

2. 上手三件套：**KEIL C51**（写代码 + 编译出 hex）→ **CH340 驱动**（让电脑识别串口）→ **PZ-ISP**（一键烧录到板子）。 \[教材 攻略 p.13-18]

3. 51 单片机 IO 口**驱动能力弱**，外设（蜂鸣器 / 数码管 / 电机）都要靠驱动芯片（ULN2003、74HC245 等），所以常说要 "**控制**而非**驱动**"。 \[教材 攻略 p.126]

4. 下载程序**推荐 PZ-ISP**（一键下载）；STC-ISP 需要 "冷启动"（先点下载再开电源），操作繁琐不推荐。 \[教材 攻略 p.15-18]

5. P0 口内部无上拉（开漏），作 IO 用必须外接上拉电阻；P1/P2/P3 是准双向口，自带弱上拉。 \[教材 攻略 p.30-31]

## 三、详细笔记

### 3.1 认识你的开发板

开发板就是一个 "单片机最小系统 + 各种外设模块" 的教学板。普中 A2 板载：LED 模块、独立按键、4×4 矩阵按键、蜂鸣器、2 个四位一体共阴数码管、LCD 接口、TFTLCD 接口、DS18B20 接口、红外接收、电机接口、ESP8266 / 蓝牙接口等。



![](../../images/board_overview.png)

*图：开发板功能模块总览（截图自攻略第 3 章）*

芯片丝印阅读（以 STC89C52RC 为例）：\[教材 攻略 p.25]



* **STC**：宏晶公司产品

* **89**：8051 内核 + Flash 存储器

* **C**：CMOS 工艺

* **52**：Flash 大小 = 5×4KB = 8KB（51 是 4KB）

* **RC**：内部 RAM 512B（RD+ 为 1280B）

* **40I**：最高晶振 40MHz，工业级温度

### 3.2 安装 KEIL C51

安装包在 `E:\学习资料\5--开发工具\1-KEILC51软件\C51V901.exe`（含破解工具 keygen\_new2032.zip）。

要点：



1. 按默认路径安装 C51V901.exe（注意：是 C51 版本，不是 MDK-ARM 版本）

2. 用注册机生成 License，填入 KEIL 完成激活

3. 新建工程时选芯片 **STC89C52RC**（或 AT89C52 兼容型号）

> KEIL 软件仿真可用来精确测量延时时间：Options → Target → 填 Xtal 11.0592 → 设断点 → 仿真运行看 sec 差值。[教材 攻略 p.117-119]

### 3.3 安装 CH340 驱动（USB 转串口）

驱动在 `E:\学习资料\5--开发工具\2-开发板CH340驱动\SETUP.EXE`。



* 大多数系统插上 USB 会自动装好；没装好就双击 SETUP.EXE → 点 "安装"。\[教材 攻略 p.13]

* **安装失败解决**（按顺序试）：\[教材 攻略 p.13-14]

1. 打开 "安装失败解决办法" 目录装对应系统的驱动

2. 换一根 USB 线（安卓数据线即可）重试

3. 把对应系统文件夹里的 `serenum.sys`、`serial.sys` 复制到 `C:\Windows\System32\drivers`（有同名文件先删除）

4. Win8 以上可尝试关闭数字签名

* 验证：打开 PZ-ISP，能看到带 "CH340" 字样的串口号即成功。

### 3.4 烧录程序（下载 hex）

**推荐 PZ-ISP**（`E:\学习资料\5--开发工具\3-程序下载软件\PZ-ISP（推荐使用）\PZ-ISP.exe`）：



1. 打开软件，确认串口号（如 `COM13 USB-SERIAL CH340`）\[教材 攻略 p.16]

2. 选芯片类型：你的板载芯片是 STC89C52RC → 选 **"STC89C52xxx-RC"**（无 RC 后缀选 "STC89C52xx"）\[教材 攻略 p.16]

3. 波特率设 **128000**（下载慢就调高，失败就调低）\[教材 攻略 p.17]

4. 点 "打开文件" 选择编译生成的 **.hex 文件**（在 Keil 工程的 Objects 或项目目录下）\[教材 攻略 p.17-18]

5. 点 "程序下载"，提示 "程序下载成功" 即完成 \[教材 攻略 p.18]

### 3.5 51 仿真器（可选）

买了普中 51 仿真器可插入单片机座在线调试，需在 KEIL 内设置（见攻略 "51 工程模块创建" 章节）。入门阶段不是必需，先学会烧录跑现象更重要。

### 3.6 51 单片机 IO 口特性（重要）



| IO 口 | 内部上拉   | 特性         | 使用注意                     |
| ---- | ------ | ---------- | ------------------------ |
| P0   | 无（开漏）  | 双向三态       | 作 IO 必须外接上拉电阻（常选 10K 排阻） |
| P1   | 有（弱上拉） | 准双向        | 作输入前先写 1                 |
| P2   | 有（弱上拉） | 准双向        | 作输入前先写 1                 |
| P3   | 有（弱上拉） | 准双向 + 第二功能 | 第二功能：串口 / 中断 / 定时器       |

\[教材 攻略 p.30-31] P0 口之所以要上拉：内部没有上拉电阻，输出高电平是 "高阻态"，不能真正输出高电平。

## 五、术语、公式或关键表达



* **CH340**：USB 转串口芯片，电脑通过它和单片机通信

* **PZ-ISP / STC-ISP**：两种程序下载软件

* **.hex**：编译生成的烧录文件（程序大小看 KEIL 输出的 code+data，不是 hex 文件大小）\[教材 攻略 p.115]

* **冷启动**：先点下载再给板子通电的下载方式（STC-ISP 需要）

* **ISP / IAP**：在系统编程 / 在应用编程，STC 芯片无需编程器即可通过串口下载

* **准双向口**：作输入前要先写 1，内部才有弱上拉（P1/P2/P3）

* **开漏（Open-Drain）**：P0 内部无上拉，高电平是高阻态

* **上拉电阻**：把 IO 口电平 "拉" 到高电平的电阻

3. KEIL 编译信息里 code/data/xdata 分别代表什么？

4. 你的板子烧录失败，可能的原因有哪些？（至少列 3 个）

5. 51 单片机为什么不能直接驱动蜂鸣器？

### 答案要点



1. PZ-ISP 一键下载免冷启动；STC-ISP 需先点下载再通电，操作复杂易错。\[教材 攻略 p.15]

2. P1 是准双向口，写 1 后内部弱上拉生效，外部低电平才能被正确读到。\[教材 攻略 p.31]

3. code = 程序占 Flash 大小，data = 内部 RAM，xdata = 外部 RAM。\[教材 攻略 p.115]

4. CH340 驱动没装好（看不到 COM 口）、芯片类型选错、波特率不合适、hex 文件选错、USB 线接触不良、P5 短接片没短接。

5. 蜂鸣器需约 30mA 电流，IO 口驱动能力弱（即使加上拉），需 ULN2003 等放大驱动。\[教材 攻略 p.126]
