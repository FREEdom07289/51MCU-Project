## 一、核心结论

1. **任何官方实验源码都是同一套骨架**：`reg52.h`（寄存器名）→ `typedef`（类型别名）→ `#define`（端口宏）→ `sbit`（位定义）→ 常量表（查表）→ 延时函数 → 若干子函数 → `main()` 主循环。看懂骨架就懂八成。[图片 源码结构]
2. **单片机 C = 标准 C + 三个专属武器**：`sfr/sbit`（操作硬件）、`code`（常量进 Flash）、中断关键字 `interrupt`。[教材 地基笔记]
3. **位运算是控制引脚的万能工具**：`&` 清零、`|` 置位、`^` 翻转、`<< >>` 移动位置。[教材 地基笔记 §3]
4. **查表法**（数组+下标）是显示类外设的标配：段码表 `gsmg_code[17]`，按下标取码，不用 if-else 堆砌。[教材 实验源码]
5. **独立写程序 = 4 步套路**：搭骨架 → 写延时 → 写子函数 → 主循环调用；先用官方工程"抄改"，再脱稿。[推断]
6. **编译错误不可怕**：80% 是少分号、括号不匹配、变量名拼写；看提示的行号和"error"字样定位。[推断]

## 三、详细笔记

### 3.1 读懂官方源码的通用骨架

打开任意基础实验的 main.c（如 5-蜂鸣器、7-动态数码管、9-矩阵按键），从上到下永远是这 8 段：

```c
#include "reg52.h"                    // ① 头文件：把所有寄存器名 sfr/sbit 都定义好
typedef unsigned int  u16;            // ② 类型别名：u8=unsigned char, u16=unsigned int
typedef unsigned char u8;
#define SMG_A_DP_PORT  P0             // ③ 宏定义：给端口起好记的名字
sbit LSA=P2^2;                        // ④ 位定义：给单个引脚起名
u8 gsmg_code[17]={0x3f,0x06,...};     // ⑤ 常量表：段码、显示数据
void delay_10us(u16 ten_us){...}      // ⑥ 延时函数：空转耗时间
void smg_display(){...}               // ⑦ 子函数：功能封装
void main(){ while(1){ ... } }        // ⑧ 主循环：程序永远在这转
```

> 记忆法：**"头型别宏位表延子主"** 8 个字，以后打开任何工程先对号入座。

### 3.2 高频语法逐个击破（都来自真实实验源码）

**① typedef：给类型起短名（实验5/6/7/9 都有）**
```c
typedef unsigned char u8;    // 以后 u8 就是 unsigned char
u8 i;                        // 等价于 unsigned char i;
```
作用：写起来短，且换平台改一处即可（标准C也有，不是单片机专属）。

**② #define：文本替换（宏）**
```c
#define SMG_A_DP_PORT P0     // 编译时把所有 SMG_A_DP_PORT 换成 P0
#define KEY_MATRIX_PORT P1
```
作用：代码里写的是"语义名"，想换引脚只改这一行。

**③ sbit：给引脚位起名（实验7/9）**
```c
sbit LSA=P2^2;  sbit LSB=P2^3;  sbit LSC=P2^4;
```
`P2^2` 表示 P2 寄存器的第 2 位（注意：这里 `^` 是 sbit 专用语法，不是异或）。

**④ 数组查表：显示类核心技巧（实验6/7）**
```c
u8 gsmg_code[17]={0x3f,0x06,0x5b,0x4f,0x66,0x6d,0x7d,0x07,
                  0x7f,0x6f,0x77,0x7c,0x39,0x5e,0x79,0x71};
SMG_A_DP_PORT = gsmg_code[0];   // 下标0 → 0x3f → 数码管显示"0"
```
查表 = 用下标取数组元素，取代一大串 if-else。

**⑤ 循环：for 控制次数，while(1) 永不结束（语法示例；实验5 官方用的是 while 循环）**
```c
for(i=0;i<2000;i++){...}   // 执行2000次
while(1){...}              // 主程序死循环：单片机程序不能"跑完退出"
```

**⑥ switch-case：按值分流（实验7 动态数码管位选）**
```c
switch(i){                     // i=0~7，依次选通 8 位数码管
  case 0: LSC=1;LSB=1;LSA=1; break;   // A2A1A0=111 → 译码 Y7 → 最左位
  case 1: LSC=1;LSB=1;LSA=0; break;   // 110 → Y6
  case 2: LSC=1;LSB=0;LSA=1; break;   // 101 → Y5
  ...
  case 7: LSC=0;LSB=0;LSA=0; break;   // 000 → Y0 → 最右位
}
```
> 注意：这是实验 7 动态数码管官方源码的真实位选写法；每个 case 结尾的 `break;` 不能漏，否则会"穿透"到下一个 case。[教材 实验7源码]

**⑦ 函数：带参、返回值（实验9）**
```c
u8 key_matrix_ranks_scan(){ ... return 1; }   // 返回值=键值
void delay_10us(u16 ten_us){ while(ten_us--); } // 形参
```
- `void` = 无返回值；`u8` 开头 = 返回一个字节
- 形参 `u16 ten_us` 是函数内部副本，函数里改它不影响调用处

**⑧ 位运算：控制引脚的最强工具（实验5 蜂鸣器）**
```c
BEEP = !BEEP;              // 翻转：0变1、1变0（!是逻辑非）
P2 &= 0xFE;                // 清零某位（见地基笔记 §3）
P2 |= 0x01;                // 置位某位
```
翻转还可以写 `BEEP = ~BEEP;`（按位取反）——蜂鸣器实验用 `!`，单 bit 两者等价。

**⑨ 循环移位 _crol_（流水灯实验4）**
```c
#include <intrins.h>       // 用 _crol_ 必须包含它
P2 = _crol_(P2,1);         // P2整体循环左移1位：1111 1110 → 1111 1101
```

**⑩ 运算符优先级提醒（高频坑）**
```c
while(ten_us--);           // 先判断 ten_us 是否为真，再自减 —— 延时就是靠它
```
`ten_us--` 是"先用后减"；`--ten_us` 是"先减后用"。写错延时时间会差 1。

### 3.3 独立写程序的 4 步套路

**第 1 步：搭骨架**（照抄官方模板，永远先写这几行）
```c
#include "reg52.h"
typedef unsigned int u16;
typedef unsigned char u8;
```

**第 2 步：定义硬件**（你要控制什么就定义什么）
```c
sbit BEEP = P2^5;              // 蜂鸣器接 P2.5（查硬件设计）
#define KEY_PORT P1             // 按键在 P1
```

**第 3 步：写功能子函数 + 延时**（把"要做的事"拆成函数）
```c
void delay_10us(u16 t){ while(t--); }
void beep_once(){ u16 i; for(i=0;i<100;i++){ BEEP=!BEEP; delay_10us(100);} BEEP=0; }
```

**第 4 步：主循环调用**
```c
void main(){ while(1){ beep_once(); delay_10us(20000); } }
```

> 独立写的信心来自"抄改"：先把官方工程跑通，再改 1 个参数看现象变化，最后才脱稿写自己的。

### 3.4 编译错误排错速查（KEIL 报错怎么看）

| 报错特征 | 常见原因 | 修法 |
|---|---|---|
| `syntax error` + 行号 | 缺分号/括号不匹配 | 看报错行，往前找漏掉的 `;` `}` |
| `undeclared identifier` | 变量没定义/拼写错 | 检查名字大小写 |
| `missing ';'` | 上一条语句漏分号 | 修上一行 |
| `'xxx' redefinition` | 重复定义 | 检查是否定义了两次 |
| Build 成功但没现象 | hex 没烧进去 / 引脚定义错 | 重烧录；核对 sbit 对应引脚 |

## 四、例题、案例或实验

**改造练习（选一个做，每个都是"改1处看现象"）：**

1. **蜂鸣器变调**：把 `delay_10us(100)` 改成 `delay_10us(50)` → 声音变高（频率变快）；改成 200 → 声音变低沉。
2. **静态数码管换字**：`SMG_A_DP_PORT=gsmg_code[0]` 改 `[2]` → 显示"2"；改 `[10]` 显示"A"。
3. **流水灯反向**：`P2=_crol_(P2,1)` 改 `_cror_(P2,1)`（右移）→ 灯从左往右变从右往左。
4. **矩阵按键换键值**：main 里 `gsmg_code[key-1]` 改成 `gsmg_code[key]` → 显示整体偏移 1（S1 显示"1"而不是"0"）。

**独立小任务**：自己写一个程序——按下 K1 蜂鸣器响 0.5 秒，同时数码管显示"1"，松开停止。（提示：K1 接 **P3.1**，见攻略第 13 章独立按键硬件设计；KEY1=P3^1）

## 五、术语、公式或关键表达

- **u8 / u16**：unsigned char / unsigned int 的别名
- **宏**：`#define` 文本替换，编译前完成
- **sbit**：`P2^2` 语法，给寄存器的位起名
- **查表**：数组+下标取数据
- **轮询**：主循环不停查询（while(1) 里 if）
- **形参/实参**：函数定义里的参数/调用时传入的值
- **`!` 逻辑非** vs **`~` 按位取反**：单 bit 等价，多 bit 不同
- **`--` 先用后减 vs 先减后用**：`while(t--)` 与 `while(--t)` 差 1 次

### 主动回忆题

1. `sbit LSA=P2^2;` 里的 `^` 是什么意思？和异或 `^` 有区别吗？
2. 为什么 `#define SMG_A_DP_PORT P0` 而不是用变量？
3. `while(ten_us--);` 和 `while(--ten_us);` 有什么区别？
4. 想只翻转 P2 的第 3 位、不动其他位，怎么写？
5. 数码管显示"0"为什么要写 `gsmg_code[0]` 而不是 `0`？

### 答案要点

1. sbit 专用语法，表示 P2 寄存器的第 2 位；和位运算异或无关，只是符号相同。[教材 地基笔记 §2.2]
2. 宏是编译前文本替换，零开销且能起语义名；变量要占 RAM 且运行期才有效。[教材 地基笔记]
3. 前者先用后减（先判断再减1），后者先减后用；影响循环次数差 1。
4. `P2 ^= (1<<3);` 即 `P2 = P2 ^ 0x08;`。[教材 地基笔记 §3.3]
5. 段码表按下标取码：gsmg_code[0]=0x3f 正好是"0"的段码；直接写 0 是让数码管显示"0"对应空段，全灭。
