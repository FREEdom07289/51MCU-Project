# 定时器与中断

> 从「软件死等」到「硬件自动干」的关键一跃。有了定时器和中断，单片机才能同时干好几件事——灯在闪、蜂鸣器在响、按键还能响应。

---

## 0. 一句话抓住核心

**定时器是"硬件自己数数"**：每过一个机器周期加 1，数到溢出就置标志位。
**中断是"CPU 放下手头的事去处理这个标志"**。

两者配合，才能摆脱 `delay()` 死等，让程序从「单任务轮询」升级为「多任务并发」。

```
没有定时器：CPU 一直在 delay() 里空转 → 什么别的也干不了
有了定时器：硬件自己数数，CPU 去干别的 → 数满了打断 CPU 去处理
```

---

## 1. 定时器/计数器基础

### 1.1 硬件资源（STC89C52RC）

- **T0**（定时器0）+ **T1**（定时器1）+ **T2**（52系列独有，定时器2）
- 每个定时器本质上是一个**加1计数器**，由 THx（高8位）和 TLx（低8位）组成 16 位寄存器
- 可以工作在**定时模式**（数机器周期）或**计数模式**（数外部引脚脉冲）

### 1.2 定时模式 vs 计数模式

| 模式 | 计数来源 | 典型用途 |
|:---|:---|:---|
| **定时模式** | 内部机器周期（12 个晶振周期 = 1 个机器周期） | 精确延时、PWM、波特率发生器 |
| **计数模式** | T0 / T1 引脚上的外部脉冲（下降沿触发） | 计数外部事件、测频率 |

由 `TMOD` 寄存器的 `C/T` 位选择。

### 1.3 机器周期与晶振

```
机器周期 = 12 / 晶振频率
```

| 晶振频率 | 机器周期 | 说明 |
|:---:|:---:|:---|
| 11.0592 MHz | 1.085 µs | 串口波特率无误差，普中A2标配 |
| 12 MHz | 1 µs | 好算，但串口有误差 |

> 为什么用 11.0592 MHz？因为 11059200 ÷ 12 = 921600 Hz，是个整数。921600 ÷ 32 ÷ 3 = 9600（常用波特率），没有累积误差。12 MHz 晶振算出来 9600 波特率误差约 8.5%，会乱码。

## 2. 定时器的四种工作方式

由 `TMOD` 寄存器的 M1、M0 两位决定：

| 方式 | M1 M0 | 位数 | 特点 | 典型用途 |
|:---:|:---:|:---:|:---|:---|
| 方式 0 | 00 | 13 位 | 兼容老 8048，TL 只用低 5 位 | 极少用，历史遗留 |
| **方式 1** | **01** | **16 位** | 最常用，最大 65536 个机器周期，需手动重装初值 | 通用定时、PWM |
| 方式 2 | 10 | 8 位自动重装 | TH 存初值，TL 溢出后自动从 TH 重装 | 串口波特率发生器 |
| 方式 3 | 11 | 拆分 T0 | T0 拆成两个 8 位，T1 停止工作 | 极少用 |

### 2.1 方式 1（16 位）详解

最常用的模式。TH0 存高 8 位，TL0 存低 8 位，组成一个 16 位计数器：

```
TH0（高8位） + TL0（低8位） = 16位计数器（0 ~ 65535）
```

**工作过程**：
1. 赋初值 → 2. 每个机器周期 +1 → 3. 计满 65536 溢出 → 4. TF0 置 1 → 5. 触发中断（如果开了的话）

⚠️ **方式 1 溢出后计数器变为 0，不会自动回到初值**——必须在中断服务函数里手动重装初值。忘了就变成"只进一次中断"。

### 2.2 方式 2（8 位自动重装）详解

TH0 存初值（备份），TL0 实际计数。TL0 溢出后自动把 TH0 的值装进去，不用手动重装。

```
TH0 ──自动拷贝──► TL0（实际计数）
```

优点：不用手动重装，精度高。缺点：只有 8 位，范围只有 0~255。

**最典型用途**：串口波特率发生器（T1 方式 2）。

## 3. 初值计算（必背公式）

### 3.1 公式

```
计数个数 = 定时时间 / 机器周期
初值 = 65536 − 计数个数（方式1，16位）
初值 = 256 − 计数个数（方式2，8位）
```

### 3.2 经典例题（方式 1 定时 50ms @11.0592 MHz）

```
机器周期 = 12 / 11059200 = 1.085069... µs
50ms 内计数 = 0.05 / (12/11059200) = 50000 / 1.085069 ≈ 46080
初值 = 65536 − 46080 = 19456 = 0x4C00
TH0 = 0x4C;  TL0 = 0x00;
```

### 3.3 常用初值速查表（@11.0592 MHz）

| 定时时间 | 方式1 初值 | THx | TLx | 说明 |
|:---:|:---:|:---:|:---:|:---|
| 50 µs | 0xFFD2 | 0xFF | 0xD2 | 46 个计数 |
| 100 µs | 0xFFA4 | 0xFF | 0xA4 | 92 个计数 |
| 500 µs | 0xFE33 | 0xFE | 0x33 | 461 个计数（半毫秒） |
| 1 ms | 0xFC66 | 0xFC | 0x66 | 1毫秒 |
| 10 ms | 0xDC00 | 0xDC | 0x00 | 10毫秒 |
| 50 ms | 0x4C00 | 0x4C | 0x00 | 最常用（20次=1秒） |

> 实际写代码时可以用 STC-ISP 工具的「定时器计算器」自动生成，比手算更准。

## 4. 核心寄存器详解

### 4.1 TMOD（89H，不可位寻址）— 工作方式寄存器

高 4 位管 T1，低 4 位管 T0：

```
 bit7  bit6  bit5 bit4 │ bit3  bit2  bit1 bit0
GATE  C/T   M1   M0   │ GATE  C/T   M1   M0
        （T1）         │        （T0）
```

| 位 | 名称 | 作用 |
|:---:|:---|:---|
| GATE | 门控位 | 0：仅由 TRx 启动；1：还要 INTx 引脚为高（测脉宽用） |
| C/T | 计数/定时选择 | 0：定时模式（数机器周期）；1：计数模式（数外部脉冲） |
| M1 M0 | 方式选择 | 00=方式0，01=方式1，10=方式2，11=方式3 |

⚠️ **TMOD 不能位寻址**，不能写 `TMOD |= 0x01` 后清0吗？可以，但要先清掉对应位再设置。标准写法：

```c
TMOD &= 0xF0;   // 清掉 T0 的 4 位（保留 T1 的设置）
TMOD |= 0x01;   // T0 方式 1（16 位定时）
```

### 4.2 TCON（88H，可位寻址）— 控制寄存器

```
 bit7 bit6 bit5 bit4 bit3 bit2 bit1 bit0
 TF1  TR1  TF0  TR0  IE1  IT1  IE0  IT0
```

| 位 | 名称 | 作用 |
|:---:|:---|:---|
| TF1 / TF0 | 溢出标志 | 定时器溢出时硬件置 1；查询方式要软件清 0；中断方式硬件自动清 0 |
| TR1 / TR0 | 运行控制 | 置 1 启动定时器，清 0 停止（软件控制） |
| IE1 / IE0 | 外部中断标志 | 外部中断触发后置 1 |
| IT1 / IT0 | 外部中断触发方式 | 0=低电平触发，1=下降沿触发 |

> TCON 是可位寻址的，所以可以直接写 `TR0 = 1;`、`TF0 = 0;`。

## 5. 中断系统

### 5.1 什么是中断

```
CPU 在干主程序 → 硬件事件来了（门铃响）→ 暂停主程序 → 跳到中断服务函数
→ 处理完 → 回到主程序接着干
```

**生活比喻**：你在看书（主程序），水开了（中断事件），你放下书去关火（中断处理），处理完回来接着看书（返回主程序）。

### 5.2 51 单片机的 5 个中断源（52 系列 6 个）

| 中断号 | 中断源 | 标志位 | 向量地址 | 默认优先级 |
|:---:|:---|:---:|:---:|:---:|
| 0 | 外部中断 0（INT0 / P3.2） | IE0 | 0003H | 最高 |
| 1 | 定时器 0（T0） | TF0 | 000BH | ↓ |
| 2 | 外部中断 1（INT1 / P3.3） | IE1 | 0013H | ↓ |
| 3 | 定时器 1（T1） | TF1 | 001BH | ↓ |
| 4 | 串口（UART） | RI / TI | 0023H | 最低 |
| 5 | 定时器 2（T2，仅52系列） | TF2 | 002BH | — |

### 5.3 中断开关（IE 寄存器，A8H）

```
 EA  —  ET2  ES  ET1  EX1  ET0  EX0
```

| 位 | 名称 | 作用 |
|:---:|:---|:---|
| EA | 总中断开关 | **必须置 1**，否则所有中断都不响应 |
| ET0 / ET1 | 定时器中断允许 | 1 = 允许定时器 0/1 中断 |
| EX0 / EX1 | 外部中断允许 | 1 = 允许外部中断 0/1 |
| ES | 串口中断允许 | 1 = 允许串口中断 |
| ET2 | 定时器2中断允许 | 52系列独有 |

**口诀**：开中断 = `EA = 1` + 打开对应分开关。

### 5.4 中断优先级（IP 寄存器，B8H）

```
 —  —  PT2  PS  PT1  PX1  PT0  PX0
```

- 置 1 为高优先级，清 0 为低优先级
- 只有两级：高 / 低
- 同级中断按上表顺序响应（INT0 > T0 > INT1 > T1 > 串口）
- 高优先级中断可以打断低优先级中断（中断嵌套）

## 6. 最小可用代码骨架（定时器 0 方式 1）

### 6.1 标准模板（定时 50ms，每秒翻转一次 LED）

```c
#include <REGX52.H>

typedef unsigned int u16;
typedef unsigned char u8;

// ===== 引脚定义 =====
sbit LED = P2^0;         // 低电平点亮

// ===== 全局变量（中断与主循环共享，必须加 volatile）=====
volatile u16 g_timer0_cnt = 0;    // 定时器中断计数器
volatile u8  g_led_flag = 0;      // LED 状态标志

// ===== 定时器0初始化 =====
void Timer0_Init(void)
{
    // ① 设置 TMOD：T0 方式 1（16 位定时）
    TMOD &= 0xF0;        // 清掉 T0 的 4 位
    TMOD |= 0x01;        // T0 方式 1

    // ② 赋初值：50ms @11.0592MHz
    TH0 = 0x4C;
    TL0 = 0x00;

    // ③ 开中断
    ET0 = 1;             // 允许 T0 中断
    EA  = 1;             // 开总中断

    // ④ 启动定时器
    TR0 = 1;
}

// ===== 定时器0中断服务函数 =====
void Timer0_ISR(void) interrupt 1
{
    // ⚠️ 方式 1 必须手动重装初值！
    TH0 = 0x4C;
    TL0 = 0x00;

    g_timer0_cnt++;
    if (g_timer0_cnt >= 20)   // 20 × 50ms = 1s
    {
        g_timer0_cnt = 0;
        g_led_flag = !g_led_flag;
    }
}

// ===== 主函数 =====
void main(void)
{
    Timer0_Init();

    while (1)
    {
        // 主循环里做其他事情
        if (g_led_flag)
            LED = 0;   // LED 亮
        else
            LED = 1;   // LED 灭
    }
}
```

### 6.2 为什么用标志位而不是直接在中断里操作？

| 做法 | 优点 | 缺点 |
|:---|:---|:---|
| 中断里直接操作硬件 | 简单直接 | 中断函数变长，影响其他中断 |
| 中断里只改标志位，主循环处理 | 中断极短，主循环灵活 | 需要注意变量加 `volatile` |

> 最佳实践：**中断函数越短越好**。中断里只做必须及时做的事，其他都用标志位扔给主循环处理。

## 7. 外部中断

### 7.1 两个外部中断源

| 中断 | 引脚 | 触发方式 | 中断号 |
|:---|:---|:---|:---:|
| INT0（外部中断0） | P3.2 | 低电平 / 下降沿 | 0 |
| INT1（外部中断1） | P3.3 | 低电平 / 下降沿 | 2 |

### 7.2 触发方式

由 TCON 寄存器的 IT0 / IT1 位控制：

| ITx | 触发方式 | 说明 |
|:---:|:---|:---|
| 0 | **低电平触发** | INTx 引脚为低电平时触发中断 |
| 1 | **下降沿触发** | INTx 引脚从高变低的瞬间触发一次 |

> 一般用**下降沿触发**更可靠——低电平触发时如果引脚一直低，会反复触发中断。

### 7.3 外部中断代码骨架（按键触发 INT0）

```c
#include <REGX52.H>

sbit LED = P2^0;        // INT0 固定接 P3.2，无需额外声明

void Int0_Init(void)
{
    IT0 = 1;            // 下降沿触发
    EX0 = 1;            // 允许外部中断 0
    EA  = 1;            // 开总中断
}

// 外部中断 0 服务函数
void Int0_ISR(void) interrupt 0
{
    // 按下按键触发中断，翻转 LED
    LED = !LED;
}

void main(void)
{
    Int0_Init();
    while (1)
    {
        // 主循环干别的
    }
}
```

> ⚠️ 外部中断的按键消抖怎么处理？可以在中断里加 10ms 延时再判断一次，或者用定时器扫描按键。直接在中断里延时是不好的做法（中断函数要短），更推荐的是「定时器扫描按键」。

## 8. 定时器的典型应用

### 8.1 精确延时（替代软件延时）

软件延时不准，而且占用 CPU。定时器延时精确，而且 CPU 可以干别的。

### 8.2 PWM（脉冲宽度调制）—— 呼吸灯

PWM 就是在固定周期内，调整高电平和低电平的比例，来模拟"平均电压"。

```
周期固定（如 1ms）：
  高电平占 10% → 平均电压 0.5V → LED 很暗
  高电平占 50% → 平均电压 2.5V → LED 中等亮度
  高电平占 90% → 平均电压 4.5V → LED 很亮
```

**实现方法**：定时器定时很短的时间（如 100µs），累计计数到一个周期后重置，根据占空比决定输出高/低电平。

### 8.3 定时器扫描按键（替代 delay 消抖）

每 10ms 扫描一次按键状态，软件消抖 + 按键处理都在定时器中断里做。主循环完全不用管按键。

### 8.4 动态数码管刷新

每 1ms 切换一个数码管位，视觉暂留效应让人眼觉得所有数码管都在亮。

## 9. 常见坑与避坑指南

### 9.1 方式 1 忘了重装初值

```c
void timer0_isr(void) interrupt 1
{
    // ❌ 忘了重装 TH0/TL0
    // 结果：第一次溢出后进中断，之后计数器从0开始数，
    // 下次溢出要 65536 个周期（约 71ms），而且越来越不准
}

void timer0_isr(void) interrupt 1
{
    // ✅ 进入中断第一件事就是重装初值
    TH0 = 0x4C;
    TL0 = 0x00;
    // 然后干别的
}
```

### 9.2 中断函数太长

- ❌ 中断里放 `delay()`、长循环、`printf`
- ✅ 中断里只做最必要的事，其他用标志位通知主循环

### 9.3 共享变量不加 `volatile`

中断和主循环共享的变量，要加 `volatile` 关键字，防止编译器优化掉：

```c
// ❌ 可能被编译器优化，主循环读不到中断的更新
unsigned int cnt = 0;

// ✅ 告诉编译器：这个变量会被外部（中断）修改，别优化
volatile unsigned int cnt = 0;
```

> Keil C51 里这个问题相对少一些（优化级别低），但养成好习惯是对的，以后学 STM32 肯定会遇到。

### 9.4 中断函数写错中断号

```c
void timer0_isr() interrupt 0   // ❌ 中断号 0 是外部中断0！
{
    // 结果：定时器溢出了不会进这个函数
    // 反而外部中断0触发了会进这里，完全乱套
}

void timer0_isr(void) interrupt 1   // ✅ 定时器0的中断号是 1
```

**一定要背下来**：0=外部中断0，1=定时器0，2=外部中断1，3=定时器1，4=串口。

### 9.5 中断函数有返回值或参数

中断函数**不能有返回值、不能传参数**——它是硬件自动调用的，没有谁给它传参，也没有谁接收返回值。

```c
int timer0_isr(int x) interrupt 1   // ❌ 编译报错或行为异常
```

### 9.6 忘了开 EA 总开关

```c
ET0 = 1;    // 开了 T0 分开关
// 但忘了 EA = 1; → 所有中断都不响应！
```

## 11. 学习路线建议

```
第一步：定时器查询方式
  └─ 不开启中断，用 if (TF0 == 1) 判断溢出
     （先理解"硬件数数"这个概念）

第二步：定时器中断方式
  └─ 开中断，在中断服务函数里处理
     （理解"打断主程序"的概念）

第三步：外部中断
  └─ 按键接 INT0/INT1，按下触发中断
     （理解外部中断触发方式）

第四步：进阶应用
  ├─ PWM 呼吸灯
  ├─ 定时器扫描按键
  ├─ 定时器做数码管刷新
  └─ 输入捕获 / 脉冲测量
```
