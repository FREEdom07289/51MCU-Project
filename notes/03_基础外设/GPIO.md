# GPIO — 通用输入输出端口

> GPIO = General-Purpose Input/Output，是单片机最基础的硬件引脚。**学单片机本质上就是学怎么让这些引脚输出电平、读取电平。**

---

## 1. 核心概念

### 1.1 GPIO 是什么

GPIO 是可以由程序自由配置的引脚，有两种基本模式：

| 模式 | 作用 | 典型应用 |
|:---|:---|:---|
| **输出模式（Output）** | 引脚输出高电平 / 低电平，控制外部器件 | LED 亮灭、继电器开关、蜂鸣器启停 |
| **输入模式（Input）** | 读取外部电平信号 | 按键按下、传感器高低电平信号 |

**关键特点**：
- 通用性：没有固定专属功能，想用做输入就做输入，想用做输出就做输出
- 电平标准：大多是 3.3V 或 5V 逻辑电平
- 只能识别高低电平，不能直接读取模拟电压（模拟信号需要 ADC）

### 1.2 常见例子

- 51 单片机、STM32、ESP32、树莓派上一排排引脚，基本都是 GPIO
- 流水灯程序，就是循环切换一组 GPIO 的输出电平

### 1.3 简单对比

| 类型 | 信号 | 典型代表 |
|:---|:---|:---|
| GPIO | 数字开关量（0/1） | 按键、LED、继电器 |
| ADC | 模拟电压量（连续电压数值） | 温度传感器、电位器 |

## 2. 51 单片机的 GPIO（P0 ~ P3）

STC89C52RC 有 **4 组 8 位 I/O 口**，共 32 个引脚：P0、P1、P2、P3。每组都有对应的特殊功能寄存器。

| 端口 | 地址 | 位数 | 特点 | 普中A2板上的主要功能 |
|:---|:---:|:---:|:---|:---|
| **P0** | 0x80 | 8位 | 开漏输出，需外接上拉电阻 | 数据总线（数码管段选/点阵等） |
| **P1** | 0x90 | 8位 | 准双向口，内部有上拉 | 矩阵按键、LCD1602 等 |
| **P2** | 0xA0 | 8位 | 准双向口，内部有上拉 | LED、数码管位选、蜂鸣器 |
| **P3** | 0xB0 | 8位 | 准双向口，内部有上拉，有第二功能 | 独立按键、串口、外部中断、定时器 |

### 2.1 什么是「准双向口」

51 单片机的 P1/P2/P3 都是**准双向口**——它既是输入又是输出，但不是真正的双向（没有方向寄存器）。

**核心特点**：
- 输出低电平时：内部 MOS 管导通，拉到地，灌电流能力强（~20mA）
- 输出高电平时：内部上拉电阻拉到 VCC，拉电流能力弱（~100µA）
- 做输入时：必须先写「1」，让内部上拉把引脚拉到高电平，然后外部电路才能把它拉低

```
准双向口做输入的正确步骤：
  ① 先写 1（让内部上拉生效，引脚变为高电平）
  ② 再读引脚（外部电路如果是低电平，就能把引脚拉低）
```

> 💡 为什么叫「准」双向？因为它没有单独的方向控制寄存器，输入和输出共用一个端口。做输入前要先写 1，这是 51 单片机的经典特点。

### 2.2 P0 口的特殊性

P0 口是**开漏输出**结构，内部没有上拉电阻：

| 特点 | 说明 |
|:---|:---|
| 开漏输出 | 只能输出低电平（拉到地），不能输出高电平（高阻态） |
| 做输出用 | 必须外接上拉电阻（普中A2板上已有排阻） |
| 做输入用 | 也要先写 1（和准双向口一样） |
| 驱动能力 | 灌电流比 P1/P2/P3 更强 |

> 普中 A2 开发板上 P0 口已经接了 10K 排阻作为上拉，所以使用时和其他端口看起来一样。但你要知道原理上的区别。

## 3. 拉电流 vs 灌电流

这是 51 单片机 GPIO 最重要的概念之一，直接决定了 LED 为什么是低电平点亮。

### 3.1 定义

| 类型 | 电流方向 | 51 单片机能力 |
|:---|:---|:---|
| **拉电流（Source）** | 电流从单片机引脚**流出** → 负载 → GND | 很弱（约 100µA 级，点不亮 LED） |
| **灌电流（Sink）** | 电流从 VCC → 负载 → **流入** 单片机引脚 | 较强（单个引脚约 10–20 mA） |

### 3.2 为什么 LED 要低电平点亮

```
❌ 高电平点亮（拉电流）：引脚 → LED → GND
   电流从引脚流出，51 拉电流能力太弱 → LED 不亮或很暗

✅ 低电平点亮（灌电流）：VCC → LED → 引脚
   电流流入引脚，51 灌电流能力强 → LED 正常发光
```

详细计算和原理见 [[LED原理详解]] 和 [[拉电流]] / [[灌电流]]。

## 4. 51 单片机 GPIO 操作方式

### 4.1 整组操作（字节级）

直接给端口寄存器赋值，一次改变 8 个引脚：

```c
P2 = 0xFE;   // 1111 1110 → P2.0 输出低电平，其余高电平
P2 = 0x00;   // 0000 0000 → 全部输出低电平
P2 = 0xFF;   // 1111 1111 → 全部输出高电平
```

### 4.2 单个引脚操作（位级）

用 `sbit` 定义单个引脚，单独控制：

```c
sbit LED1 = P2^0;   // 定义 P2.0 为 LED1
sbit KEY1 = P3^1;   // 定义 P3.1 为 KEY1

LED1 = 0;           // P2.0 输出低电平 → 点亮 LED
if (KEY1 == 0)      // 读取 P3.1 电平 → 判断按键是否按下
{
    // 按键处理
}
```

`sbit` 的原理见 [[单片机C编程地基#2.2 `sbit`（Single Bit）— 位级]]。

### 4.3 位运算操作（只改某一位）

不想影响其他引脚时，用位运算：

| 操作 | 代码 | 说明 |
|:---|:---|:---|
| 点亮第 n 位（置0） | `P2 &= ~(1 << n);` | 按位与，第n位清零 |
| 熄灭第 n 位（置1） | `P2 |= (1 << n);` | 按位或，第n位置1 |
| 翻转第 n 位 | `P2 ^= (1 << n);` | 按位异或，第n位取反 |

详细位运算口诀见 [[单片机C编程地基#3. 位运算实战：怎么点某一盏灯 / 关某一位]]。

## 5. P3 口的第二功能

P3 口的每个引脚都有第二功能，这是 51 单片机资源复用的经典设计：

| 引脚 | 第一功能（IO） | 第二功能 | 说明 |
|:---:|:---|:---|:---|
| P3.0 | 普通IO | **RXD** | 串口接收 |
| P3.1 | 普通IO | **TXD** | 串口发送 |
| P3.2 | 普通IO | **INT0** | 外部中断 0 |
| P3.3 | 普通IO | **INT1** | 外部中断 1 |
| P3.4 | 普通IO | **T0** | 定时器 0 外部计数输入 |
| P3.5 | 普通IO | **T1** | 定时器 1 外部计数输入 |
| P3.6 | 普通IO | **WR** | 外部 RAM 写选通 |
| P3.7 | 普通IO | **RD** | 外部 RAM 读选通 |

> 普中 A2 板上，独立按键 K1~K4 接在 P3.1/P3.0/P3.2/P3.3 上——这几个引脚同时也是串口和外部中断引脚！做串口实验时要注意拔掉按键跳线帽，避免互相干扰。

## 6. GPIO 使用注意事项

### 6.1 输入前先写 1

```c
// ❌ 错误：直接读，可能读到的不是真实电平
if (P3_1 == 0) { ... }

// ✅ 正确：先写 1，再读
P3_1 = 1;
if (P3_1 == 0) { ... }
```

> 实际中，如果你一直把引脚当输入用，上电后默认就是高电平（有上拉），所以可以直接读。但如果之前你把它当输出写过 0，再做输入前一定要先写 1。

### 6.2 灌电流总和限制

单个引脚灌电流约 20mA，但**整个端口的总灌电流有限制**（P0 约 26mA，其他口约 15mA）。如果 8 个 LED 同时亮，总电流可能超过限制，实际使用中要注意。

### 6.3 引脚复用冲突

普中 A2 板上很多引脚是复用的：
- P2.2/P2.3/P2.4：LED + 数码管位选（74HC138）
- P2.5：LED + 蜂鸣器
- P3.0/P3.1：按键 + 串口
- P3.2/P3.3：按键 + 外部中断

做实验时，如果某个模块工作不正常，检查一下是不是被其他模块干扰了，拔掉对应的跳线帽试试。

## 7. 与其他单片机 GPIO 的对比

| 特性 | 51 单片机 | STM32 | ESP32 / Arduino |
|:---|:---|:---|:---|
| 方向控制 | 无方向寄存器（准双向） | 有方向寄存器（GPIO_MODER） | `pinMode(pin, INPUT/OUTPUT)` |
| 上拉电阻 | P0 没有，P1/P2/P3 有 | 可配置上拉/下拉 | 可配置上拉/下拉 |
| 驱动能力 | 灌电流强、拉电流弱 | 对称，都比较强 | 对称 |
| 速度 | 慢（~12MHz 晶振） | 快（几十 MHz ~ 几百 MHz） | 快 |
| 复用功能 | P3 有第二功能 | 每个引脚都有多个复用功能 | 每个引脚都有多个功能 |

> 学完 51 的 GPIO，再学 STM32 的 GPIO 就很好理解——STM32 只是多了方向寄存器、更多的复用功能、更快的速度。基本思想是一样的。
