# LED 原理详解

> 📝 初稿：由整理流程新建（用于修复 LED 原理卡断链），细节待你核对补充。

## 一句话

LED 在 51 单片机上**低电平点亮**：因为 51 的 I/O 口「灌电流（sink）能力强、拉电流（source）能力弱」，所以电路接成「VCC → LED → 限流电阻 → 单片机引脚」，引脚输出 0 时形成回路。

## 为什么会这样

| 驱动方式 | 电流方向 | 51 单片机能力 |
|:--|:--|:--|
| 拉电流（输出高电平点亮） | 引脚 → 负载 | 很弱（约 100 µA 级，点不亮 LED） |
| 灌电流（输出低电平点亮） | 负载 → 引脚 | 较强（单个引脚约 10–20 mA） |

> 普中 A2 板子已经把 LED、限流电阻接好，我们只需要拉低对应引脚。
> 具体数值见 [[模块原理图]]，能力边界见 [[拉电流]] / [[灌电流]]。

## 限流电阻怎么算

```
R = (VCC − VF) / IF
以红色 LED 为例：VF ≈ 1.8 V，IF 取 5–10 mA，VCC = 5 V
R = (5 − 1.8) / 0.01 ≈ 320 Ω  → 实际常用 470 Ω ~ 1 kΩ
```

- 电阻太小 → 电流过大，烧 LED 或损伤引脚。
- 电阻太大 → 亮度不足。

## 三种最基础的写法

```c
#include <reg52.h>
sbit LED1 = P2^0;

void main() {
    LED1 = 0;                 // ① 点亮
    while (1);                //    停在死循环（单片机没有操作系统）
}
```

```c
// ② 闪烁：延时 + 翻转
void delay(unsigned int ms) {           // 约 1 ms @11.0592 MHz（粗略）
    unsigned int i, j;
    for (i = ms; i > 0; i--)
        for (j = 110; j > 0; j--);
}

while (1) {
    LED1 = ~LED1;         // 取反
    delay(500);
}
```

```c
// ③ 流水灯：P2 口整体移位
unsigned char i;
for (i = 0; i < 8; i++) {
    P2 = ~(1 << i);       // 低电平点亮第 i 个
    delay(200);
}
```

## 常见错误

- **忘记死循环** `while(1)`：main 跑完会复位/乱跑，看起来像"闪一下就灭"。
- **位与字节混用**：`P2 = 0xFE` 会一次改 8 个引脚；只想动一个引脚用 `sbit`。
- **高电平点亮接法**：如果换成「引脚 → LED → GND」，就会变成高电平点亮，逻辑正好相反——看原理图确认。
- **P0 口特殊性**：P0 是开漏结构，做 I/O 时需要外接上拉电阻（普中 A2 板上已有）。
