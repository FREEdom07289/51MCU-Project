# 74HC595 — 8 位串入并出移位寄存器

> 用 3 根线换来 8 根并行输出，还能级联扩展。**LED 点阵、数码管位选扩展、IO 口不够用时的救星。**

---

## 0. 一句话抓住核心

**74HC595 用 3 根线（数据 + 移位时钟 + 锁存时钟）换来 8 根并行输出**，还能多片级联；LED 点阵、多个数码管就靠它省引脚。

核心思想：**串行输入 → 移位寄存器 → 锁存 → 并行输出**。两级结构是关键——移位时输出不变，锁存后 8 位同时更新。

---

## 1. 内部结构与工作原理

### 1.1 两级结构

```
DS ──► [ 8 位移位寄存器 ] ──锁存──► [ 8 位输出锁存器 ] ──► Q0 … Q7
            ▲         ▲                    ▲
          SHCP      STCP                  OE̅ (低有效)
```

**两级寄存器**：
1. **移位寄存器**：接收串行数据，一位一位往里移
2. **输出锁存器**：保存当前输出值，锁存后才更新

为什么要两级？
- 移位过程中输出**保持不变**（不会出现"逐位闪"的鬼影）
- 8 位移完后，**锁存一下同时输出**（干净利落）

### 1.2 工作过程动画（文字版）

```
初始状态：移位寄存器 = ???? ????，输出锁存器 = 0000 0000

发送第一个位（最高位）：
  DS = 1，SHCP 上升沿 → 移位寄存器 = 1??? ????

发送第二个位：
  DS = 0，SHCP 上升沿 → 移位寄存器 = 10?? ????

... 连续发 8 位后：
  移位寄存器 = 1011 0101（假设发的是 0xB5）

STCP 上升沿（锁存）：
  输出锁存器 = 1011 0101 → Q0~Q7 同时更新为对应电平
```

## 2. 引脚详解

| 引脚 | 名称 | 类型 | 作用 |
|:---:|:---|:---:|:---|
| 14 | **DS** / SER | 输入 | 串行数据输入（先送高位还是低位看程序） |
| 11 | **SHCP** / SRCLK | 输入 | 移位时钟，**上升沿**把 DS 位移入移位寄存器 |
| 12 | **STCP** / RCLK | 输入 | 锁存时钟，**上升沿**把移位寄存器内容送到输出锁存器 |
| 13 | **OE̅** | 输入 | 输出使能，**低电平有效**（常直接接地 = 一直使能） |
| 10 | **MR̅** / SCLR | 输入 | 移位寄存器复位，**低电平复位**（常接 VCC = 不复位） |
| 9 | **Q7'** | 输出 | 串行输出，接下一片的 DS（用于级联） |
| 15, 1–7 | **Q0–Q7** | 输出 | 8 位并行输出 |

### 2.1 普中 A2 板上的典型接法

LED 点阵模块（以官方 `13-LED点阵实验(显示图像)/main.c` 为准）：
- DS → P3.4
- SHCP / SRCLK → P3.6
- STCP / RCLK → P3.5
- OE̅ → GND（始终使能）
- MR̅ → VCC（不复位）

> 不同板子接法可能不同，以实际原理图为准。

## 3. 发送一个字节的时序与代码

### 3.1 标准写法（MSB 先出）

```c
// 定义引脚（以普中A2 LED点阵为例）
sbit DS   = P3^4;   // 串行数据
sbit SHCP = P3^6;   // 移位时钟（官方代码里叫 SRCLK）
sbit STCP = P3^5;   // 锁存时钟（官方代码里叫 RCLK）

// 发送一个字节到 595（高位在前）
void HC595_SendByte(unsigned char dat)
{
    unsigned char i;
    for (i = 0; i < 8; i++)
    {
        // ① 取最高位，送到 DS
        DS = dat & 0x80;   // 0x80 = 1000 0000，取第7位（最高位）
        
        // ② SHCP 上升沿：移位（先拉低再拉高 = 上升沿）
        SHCP = 0;
        SHCP = 1;
        
        // ③ 数据左移一位，准备发下一位
        dat <<= 1;
    }
    
    // ④ 8 位发完，STCP 上升沿：锁存输出
    STCP = 0;
    STCP = 1;
}
```

### 3.2 时序图（文字版）

```
DS:   [Bit7] [Bit6] [Bit5] ... [Bit0]
       ┌──┐   ┌──┐   ┌──┐       ┌──┐
SHCP: ─┘  └───┘  └───┘  └─ ... ─┘  └──
       
       ↓ 每来一个上升沿，移一位 ↓
       
移位寄存器: ←Bit7←Bit6←Bit5←...←Bit0←

                                        ┌──┐
STCP: ──────────────────────────────────┘  └──
                                        ↑
                                   锁存，8位同时输出
```

### 3.3 LSB 先出的写法（低位在前）

有些场景需要低位先发，改一下取位方式就行：

```c
void HC595_SendByte_LSB(unsigned char dat)
{
    unsigned char i;
    for (i = 0; i < 8; i++)
    {
        DS = dat & 0x01;   // 取最低位
        SHCP = 0;
        SHCP = 1;
        dat >>= 1;         // 右移
    }
    STCP = 0;
    STCP = 1;
}
```

> ⚠️ 高位在前还是低位在前，取决于你的硬件连接和显示需求。LED 点阵一般是高位在前（MSB first），但具体要看列怎么接。

## 4. 级联扩展

### 4.1 级联原理

把前一片的 Q7' 接到后一片的 DS，时钟信号并联：

```
单片机 ──DS──► [595 #1] ──Q7'──► [595 #2] ──Q7'──► ...
         SHCP ──┬───────────────┬───────────────┘   （时钟并联）
         STCP ──┘───────────────┘
```

- 数据像"排队"一样推过去
- **先发的数据最终停在最后一片**（先入后出）
- 两片 = 16 位输出，三片 = 24 位
- 级联后仍然只占 3 个 I/O 口

### 4.2 级联发送代码（两片 595 = 16 位）

```c
// 发送两个字节（级联两片 595）
// dat1 → 第一片（靠近单片机），dat2 → 第二片
void HC595_Send2(unsigned char dat1, unsigned char dat2)
{
    unsigned char i;
    
    // 先发第二片的数据（因为它在"队伍后面"）
    for (i = 0; i < 8; i++)
    {
        DS = dat2 & 0x80;
        SHCP = 0; SHCP = 1;
        dat2 <<= 1;
    }
    
    // 再发第一片的数据
    for (i = 0; i < 8; i++)
    {
        DS = dat1 & 0x80;
        SHCP = 0; SHCP = 1;
        dat1 <<= 1;
    }
    
    // 最后一起锁存
    STCP = 0;
    STCP = 1;
}
```

### 4.3 级联顺序说明

这是初学者最容易搞混的地方：

```
发送顺序：先发 B（后一片的数据），再发 A（前一片的数据）
  A ──► 移位寄存器 ──► B ──► 移位寄存器
  ↑                    ↑
第一片              第二片
（靠近单片机）     （远离单片机）

结果：
  第一片输出 A
  第二片输出 B
```

> 💡 记忆口诀：**先发的跑最远，后发的留最近**。就像排队上公交车，第一个上去的坐到最后一排。

## 5. 在 51 单片机系统中的典型应用

### 5.1 LED 点阵（最经典）

- 595 负责列数据输出（8 列 = 8 位）
- 单片机 IO 口负责行选（8 行 = 另一个 595 或直接 IO）
- 逐行扫描 + 消影 = 显示图案

详细实现见 [[LED点阵]]。

### 5.2 数码管位选扩展

- 动态数码管的位选信号，如果数码管数量多（如 8 个以上）
- 用 595 扩展位选，节省 IO 口
- 段选可以用另一片 595，也可以直接用 P0 口

### 5.3 普通 IO 扩展

- 单片机 IO 不够用时，用 595 扩展输出口
- 每片增加 8 个输出，级联 N 片增加 8×N 个
- 只需要 3 根控制线（DS、SHCP、STCP）

> ⚠️ 595 只能扩展**输出**，不能扩展输入。要扩展输入用 74HC165（并入串出）。

## 6. 与 74HC138、74HC245 的对比

| 芯片 | 功能 | 输入 | 输出 | 典型用途 |
|:---|:---|:---:|:---:|:---|
| **74HC595** | 串入并出移位寄存器 | 串行 1 位 | 并行 8 位 | LED点阵、IO扩展、数码管位选 |
| **74HC138** | 3-8 译码器 | 3 位地址 | 8 位（低有效） | 数码管位选、存储器片选 |
| **74HC245** | 八总线收发器 | 8 位并行 | 8 位并行 | 数码管段选驱动、电平转换 |

**什么时候用哪个？**
- 只要 3~8 译码 → 138（简单直接）
- 要很多输出 / 级联 → 595（扩展性强）
- 要增强驱动能力 / 双向缓冲 → 245

## 7. 常见问题与注意事项

### 7.1 为什么输出会有"鬼影"？

**原因**：移位过程中输出锁存器没锁好，或者 OE 没有配合消隐。
**解决**：
1. 确保 STCP 在 8 位数据全部移完后再拉高
2. 动态扫描时可以用 OE 配合，移位时关闭输出（高电平），锁存后再打开
3. 检查是不是硬件问题（595 坏了？接线松了？）

### 7.2 级联后数据不对

**常见原因**：
- 级联顺序搞反了（先发的应该在最后一片）
- Q7' 没接到下一片的 DS
- 时钟信号抖动（加个小电容滤波）

### 7.3 输出电流不够

74HC595 的输出电流比 51 IO 口强，但也有限（约 20mA 左右）。如果驱动很多 LED 或大功率器件，需要加驱动芯片（如 ULN2003、74HC245 等）。

### 7.4 MR 引脚一定要接 VCC

MR（主复位）是低电平有效，如果悬空可能受到干扰导致意外复位。一定要接到 VCC（高电平），确保正常工作。

### 7.5 OE 引脚的妙用

OE（输出使能）低电平有效：
- 接地 = 一直输出（最简单的用法）
- 接单片机 IO 口 = 可以控制输出开关
- 动态扫描时，移位期间把 OE 拉高（关闭输出），锁存后再拉低，可以消除鬼影
